# Bookly

Bookly is a book catalog application designed to help users discover books and manage their reading activities.

## Features

- Browse and explore books
- View book details
- Add books to favorites
- Manage personal reading lists
- Write book reviews and ratings
- Retrieve book information through the Google Books API

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js and Express.js
- **Database:** PostgreSQL
- **External API:** Google Books API
- **Version Control:** Git and GitHub
